# ⏱️ Pendulum with Friction (Маятник с трением)

Классическая задача физики — моделирование движения математического маятника с учётом вязкого трения. 

Визуализация включает:
- Временную зависимость угла `θ(t)`
- Фазовый портрет `θ, ω`
- Изменение механической энергии `E(t)`
- Анимацию движения маятника
