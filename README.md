# computational-physics-portfolio

Данный репозиторий содержит решения классических задач вычислительной физики, реализованные на Python.
Каждая программа включает аналитическое решение (где это возможно), численное решение и визуализацию.

## Навыки
- Python (NumPy, SciPy, Matplotlib, SymPy)
- Численные методы (Эйлер, RK4, метод прогонки)
- ОДУ, PDE, электродинамика, квантовая механика, статистическая физика
